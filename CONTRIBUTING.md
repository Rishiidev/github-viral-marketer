# Contributing to github-viral-marketer

Contributions are welcome!

## How to Test
This is an agent skill. To test your changes:
1. Link your modified directory to your agent's skills directory.
2. Open Claude Code or Antigravity and prompt: `"Test the github viral marketer skill on this test repo."`
3. Verify the before/after behavior.

## PR Format
Please provide a clear before/after example of how the skill behaves differently with your changes in the PR description.

## What must never change
- **No spam:** Do not modify the PR engine script to remove rate limiting or send mass PRs. Quality is the core of this strategy.

[Check our Good First Issues to get started!](https://github.com/Rishiidev/github-viral-marketer/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22)
